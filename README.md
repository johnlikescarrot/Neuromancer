# Neuromancer — Definitive Bilingual English–Vietnamese C1/C2 Edition (Final 2.0)

**Author:** William Gibson · **Output:** `output/neuromancer_bilingual_edition.pdf` (A4 PDF)

## What was verified (deep audit)
Programmatic audit before redesign found: **5 parts, 24 chapters, 2,598 aligned paragraphs, 0 empty English cells, 0 empty Vietnamese cells**. No remainder of the supplied novel was untranslated, so this final update does not invent or duplicate translation; it verifies completeness and rebuilds the edition.

## Final redesign — TypeScript + Astryx
- `src/tokens.ts` parses design tokens at build time from `@astryxdesign/theme-neutral` (Astryx, Meta — github.com/facebook/astryx → meta/astryx) generated by the Astryx CLI. Astryx is React/StyleX based, so its **token/theming model** is used for print; no claim is made that React components render inside the PDF.
- `src/build.ts` (TypeScript, pdf-lib + fontkit) generates the PDF directly: cover, study method, benchmark matrix, contents with chapter start pages (two-pass build), part/chapter pages, side-by-side EN/VI numbered paragraphs, chapter C1/C2 tasks, master glossary (55 terms), answer guidance and self-assessment.
- `data/edition_manifest.json` records pages, counts, benchmarks and chapter start pages without duplicating novel text.

## Rebuild
```bash
npm install
npm run build        # tsc + node dist/build.js -> output/neuromancer_bilingual_edition.pdf
npm run astryx -- component --list   # explore the Astryx design system used for tokens
python3 -m unittest tests/test_bilingual_edition.py
```
Legacy Python scripts in `scripts/` are retained for provenance; the TypeScript build supersedes them.
